25仔（25zai）

轻量剪贴板历史，数据只留在本机。

隐私政策 GitHub 下载

一个用 Rust + egui 写的轻量剪贴板历史工具：常驻托盘，Alt+V 唤起，点击即粘贴。 没有 Electron，没有后台云同步，数据全部留在本地的一个 redb 文件里。

下载
  • GitHub Releases（绿色版 zip / 安装包 exe / 商店包 msix）
  • 命令行：winget install Refout.25zai
  • Microsoft Store：审核中

功能

  • 文本 / 图片 / 文件列表采集，BLAKE3 连续去重
  • 全局快捷键唤起（默认 Alt+V，可在设置里改键，支持按键捕获录键）
  • 快速记录：Alt+N 打开「笔记」tab，Enter 保存、Shift+Enter 换行，笔记不会被自动清理
  • 列表排序：最近使用 / 最近创建 / 最早创建 / 按类型 / 手动排序；手动模式下拖拽或用 Ctrl+↑↓ 调整顺序
  • 点条目直接粘贴回原来的窗口；钉住窗口后可连续粘多条
  • 实时搜索：内存索引先行，命中不足时再走存储层全量搜索
  • 固定条目：钉住的历史不会被容量上限和时间清理删掉
  • 图片缩略图：按需解码、按条目缓存
  • 明暗主题：跟随系统 / 强制明 / 强制暗，主题色可调，字号可缩放
  • 多语言：简体中文 / English，可跟随系统区域
  • 开机自启：设置页一键开关，登录后台常驻不弹窗
  • 敏感内容跳过：形似密钥的内容默认不落盘
  • 单实例：第二次启动会把已有实例唤到前台，然后自己退出

隐私

不联网、不收集、不上传。剪贴板内容只写在本机的一个本地数据库文件里， 没有任何遥测、账号或云同步。详见隐私政策。

平台

Windows 11 已实测；macOS / Linux 代码路径存在但未验证。

隐私政策

25仔（25zai）· 生效日期：2026-11-03

返回首页 English
一句话总结：25仔不收集任何数据，不联网，不上传。 剪贴板内容只写入你自己电脑上的一个本地数据库文件，我们看不到、也拿不到。

1. 我们收集哪些信息

不收集任何信息。没有账号体系，没有统计埋点，没有崩溃上报， 没有广告 SDK，也没有任何第三方分析工具。

2. 剪贴板数据

当你复制文本、图片或文件列表时，25仔会把它们写入本机的一个本地数据库（redb 格式）：

  • 便携版 / 安装版：%APPDATA%\25zai
  • Microsoft Store 版：%LOCALAPPDATA%\Packages\<包族名>\LocalCache\Roaming\25zai

这些数据不会离开你的设备。25仔不提供云同步，也没有任何上传通道。

3. 网络访问

25仔唯一的网络行为是本机回环通信：界面进程与后台守护进程通过 127.0.0.1 上的临时端口交换数据（复制事件、搜索结果等）。 该连接不经过任何外部服务器，也不会访问互联网。

程序内不包含任何自动更新、遥测或远程配置请求。

4. 敏感内容

形似密钥、令牌的内容（例如私钥块、JWT）默认不会写入数据库， 以避免密码类内容被意外留存。该行为可在设置中调整。

5. 第三方

没有第三方服务、SDK 或数据共享方。若你通过 Microsoft Store 或 winget 安装， 下载与结算由 Microsoft 处理，适用其各自的隐私政策。

6. 删除你的数据

  • 在设置页清空历史记录；
  • 或直接删除上面的数据目录；
  • 卸载程序不会自动删除历史文件，需要手动删除目录。

7. 儿童

本程序不面向儿童设计，也不收集任何人的个人信息。

8. 政策变更

若本政策有变更，会更新本页面并修改上方生效日期。

9. 联系方式

有任何疑问请开 issue： github.com/refout/25zai-clipboard/issues

Privacy Policy (English)

Summary: 25zai collects nothing, connects to nothing, and uploads nothing.

25zai is a local-first clipboard history manager. Clipboard items (text, images, file lists) are written to a local redb database under %APPDATA%\25zai (or the MSIX-redirected %LOCALAPPDATA%\Packages\<PackageFamilyName>\LocalCache\Roaming\25zai). This data never leaves your device.

The only network activity is loopback IPC between the UI process and the background daemon over 127.0.0.1. There is no telemetry, no analytics, no crash reporting, no advertising SDK, no account system, and no cloud sync.

Content that looks like a secret (private key blocks, JWTs) is skipped by default and not persisted. You can delete all data from the settings page or by removing the data directory. For questions, open an issue at github.com/refout/25zai-clipboard/issues.
